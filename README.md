# Networkwalks-B084k-Week-3-Password-Cracking
Cybersecurity Lab setup Week 3
Firstly, I solved the W3-PM2 lab on my Windows machine using the Networkwalks browser-based Hash Calculator and Password Cracker. I uploaded My Locked PDF1 (for NW Tools Lab WK3-PM2).pdf to extract its hash, ran the password cracker in the browser, recovered the password password1, and unlocked the PDF file to verify access.
Next, I solved the W3-PM1 lab using Kali Linux in VirtualBox and John the Ripper. First, I extracted the hash of My Locked PDF1.pdf into hash1.txt on my Windows Desktop and shared that folder with my Kali VM through VirtualBox Shared Folders (/media/sf_Desktop). Then, I opened the Kali terminal inside /home/kali/Desktop, copied the hash file locally using cp /media/sf_Desktop/hash1.txt .and verified its $pdf$ format with cat hash1.txt. After that I ran john hash1.txt followed by john --show hash1.txt to recover the password good-luck. Finally, I went back to Windows, entered good-luck to unlock My Locked PDF1.pdf.
